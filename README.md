# 焦虑症诊断系统

一个基于 Vue3 + Ant Design Vue 3 的纯前端焦虑症自我评估应用。

## ✨ 功能特性

- 📋 **专业评估**：包含 30 道题目，基于 GAD-7 和 SAS 标准量表
- 🎯 **等级判断**：根据得分自动判断焦虑程度（正常/轻度/中度/重度）
- 💡 **专业建议**：提供就医建议、用药参考和生活注意事项
- 💾 **本地缓存**：答题进度自动保存，支持中断续答
- 📊 **历史记录**：记录历史测试结果，方便追踪变化
- 📥 **报告导出**：支持生成并下载评估报告图片
- 🔒 **隐私保护**：所有数据存储在本地，不上传服务器

## 🚀 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 8.0.0

```bash

```


### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 🎯 核心功能说明

### 1. 评估系统

- **30 道专业测试题**，涵盖：
  - GAD-7 核心症状（7 题）
  - 躯体化症状（8 题）
  - 睡眠问题（5 题）
  - 认知和情绪症状（5 题）
  - 社交和功能影响（5 题）

### 2. 评分标准

| 等级 | 分数范围 | 颜色标识 |
|------|---------|---------|
| 正常 | 0-20 分 | 🟢 绿色 |
| 轻度焦虑 | 21-40 分 | 🟡 黄色 |
| 中度焦虑 | 41-60 分 | 🟠 橙色 |
| 重度焦虑 | 61-90 分 | 🔴 红色 |

### 3. 数据存储

使用 `localStorage` 持久化存储：

- `anxiety_assessment_answers`：当前答题进度
- `anxiety_assessment_history`：历史测试记录

## 🛠️ 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Ant Design Vue 3** - 企业级 UI 组件库
- **Pinia** - Vue 官方状态管理库
- **Vue Router** - 官方路由管理器
- **Vite** - 下一代前端构建工具
- **html2canvas** - 网页截图生成图片

## ⚠️ 免责声明

## 📝 使用说明

### 答题流程

1. 点击「开始评估」进入答题页面
2. 根据实际情况选择最符合的选项
3. 可随时暂停，进度会自动保存
4. 完成所有题目后查看结果
5. 可下载报告或重新测试

### 查看历史记录

1. 在首页或导航栏点击「历史记录」
2. 查看所有历史测试记录
3. 可删除单条记录或清空全部

### 导出报告

1. 在结果页面点击「导出报告」
2. 系统自动生成 PNG 图片
3. 图片会自动下载到本地
